# PETAVU — سند حاکم (Specification)

این پوشه، سند حاکمِ پروژه است: هر تصمیم معماری، هر جدول، هر مسیر HTTP و هر
کامپوننت رابط کاربری باید به بندی از این سند ارجاع بدهد. هیچ فیچری بیرون از این
سند ساخته نمی‌شود.

## وضعیت این دو فایل

این دو فایل، استخراجِ ساختاریافتهٔ همان دو پرامپتی هستند که کاربر به‌عنوان
مبنای کار ارائه کرده است. شماره‌بندی بندها حفظ شده تا ارجاع‌دادن در کد و
مستندات ممکن باشد.

**قاعدهٔ حاکم:** این دو فایل جز برای ثبت «شبههٔ رفع‌شده» (clarification) تغییر
نمی‌کنند. اگر متن اصلی پرامپت‌ها دوباره ارائه شود، عیناً کنار همین دو فایل
ذخیره می‌شود و همین‌ها به آن ارجاع می‌دهند.
