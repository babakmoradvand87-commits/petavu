# ADR-0020 — پنل‌های مستقل و BFF بدون منطق دامنه

تاریخ: ۲۰۲۶-۱۰-۰۴؛ وضعیت: پذیرفته؛ مرجع: §5، §15، §26–28، §56، §191.

پنل عضو و مدیریت میزبان‌های مستقل با کوکی host-only هستند. لایهٔ SSR فقط HTML/فرم و انتقال API را انجام می‌دهد؛ هیچ Repository یا SQL در `panel/` مجاز نیست. مجوز/RLS در API/DB مرجع نهایی است. منو و ویجت در DB تعریف می‌شوند؛ داده نمی‌تواند SQL/JS تولید کند.

POST محدود به فرم ۶۴KiB، مبدأ همین سطح و توکن امضاشدهٔ مرتبط با نشست است. API دوباره مبدأ و CSRF را می‌سنجد. برابری رشتهٔ توکن با توکن تازهٔ `/auth/session` غلط است: هر صدور nonce مستقل دارد. فرم‌های همزمان تا انقضا معتبر می‌مانند. پاسخ‌های نشست no-store/noindex و هدایت PRG داخلی‌اند. Set-Cookie آرایه است، نه رشتهٔ ادغام‌شده؛ راز API فقط در پاسخ مستقیم یک‌بار دیده می‌شود.

پروفایل عمومی و خواندن داخلی عضو مسیرهای جدا دارند. ذخیرهٔ پروفایل به تابع پارامتری، مجوزدار، قفل‌دار و نسخه‌دار DB منتقل شد؛ درج نخست دیگر مقادیر را گم نمی‌کند. SQLSTATE `P0409` تعارض نسخه (۴۰۹) است و با serialization failure واقعی (۴۰۰۰۱، قابل retry) یکی نیست.

هزینه: SSR و API یک رفت‌وبرگشت داخلی اضافه دارند؛ امنیت و یک منبع حقیقت از کم‌کردن یک hop مهم‌تر است. منابع CSS مشترک و content-hashed هستند؛ چیدمان و توکن‌های سطح خصوصی مستقل‌اند. سطوح را می‌توان جداگانه با همان image و Site originهای مجاز اجرا کرد.
