# ADR-0010 — لایهٔ دسترسی به داده: زمینه، نشانگر، نسخه

- **تاریخ:** ۲۰۲۶-۱۰-۰۲
- **وضعیت:** پذیرفته
- **مرجع:** §52–۵۵، §78، §93؛ Addendum §19–۲۰، §102

## زمینه

اسکیما ساخته و آزموده است، ولی هنوز هیچ کدی با آن حرف نمی‌زند. اگر هر ماژول
مستقیم به درایور وصل شود، پنج قاعده به‌سرعت فراموش می‌شوند و فراموش‌شدنِ هر یک،
یا نشت داده است یا خطای کاربر یا پرس‌وجوی کند. این ADR آن پنج قاعده را در یک
پکیج جمع می‌کند تا «فراموش‌شدنی» نباشند.

## تصمیم‌ها

### ۱. زمینه از راه GUC محلیِ تراکنش، نه پارامتر تابع

`app.user_id`، `app.business_id`، `app.session_id`، `app.platform_role`،
`app.impersonated_by`، `app.request_id` با `set_config(key, value, true)` ست
می‌شوند. RLS درست کار می‌کند، هر رخداد و حسابرسی خودکار بازیگر می‌گیرد، و
نشست بعدی روی همان اتصال، هویت اشتباه نمی‌گیرد.

**جایگزین رد‌شده:** پارامتر در هر تابع دامنه. هر کوئری می‌توانست بازیگر را جا
بیندازد؛ یک جا افتادن یعنی یک ردیف که به نام کس دیگری نوشته می‌شود.

### ۲. `DAL` به یک کلاینت بسته می‌شود؛ درون تراکنش، `createDal(tx)`

روی اتصال تک‌نفره، پرس‌وجو با کلاینت بیرونی هنگام باز‌بودن تراکنش قفل می‌کند؛
و روی استخر، زمینهٔ درست با اتصال اشتباه اجرا می‌شود. قرارداد: برای کار
درون‌تراکنشی، DAL را روی همان کلاینت تراکنش بسازید. هزینه‌اش صفر است (نه
اتصال تازه، نه استخر تازه).

### ۳. صفحه‌بندی فقط با نشانگر

`(key, id)` دوتایی، به‌علاوهٔ **اندازهٔ صفحه + ۱** ردیف. شمارش کل، ممنوع نیست،
ولی هیچ فهرستی به آن وابسته نیست: `count(*)` روی جدول بزرگ، هر بار کل جدول را
می‌خواند و صفحه‌بندی را کند می‌کند بدون آنکه چیزی درست کند.

### ۴. کنترل نسخه با ۴۱۲

`update ... where id = $ and version = $` و رکورد بی‌نتیجه ⇒ `precondition_failed`.
`409 conflict` برای «با دادهٔ موجود نمی‌سازد» می‌ماند (تعارض یکتایی). قاطی‌کردن
این دو، رابط را وادار می‌کند یک پیام عمومی و بی‌فایده نشان دهد.

### ۵. خطای دیتابیس هرگز به کاربر نمی‌رسد

`mapDatabaseError` کد می‌شناسد و پیام دامنه می‌سازد؛ متن اصلی در `cause` می‌ماند
(برای لاگ) و در `message` نمی‌آید. آزمون، نبود نام جدول در پیام را بررسی می‌کند.

### ۶. `select *` ممنوع، به‌صورت اجرایی

`assertStatementSafe` هر پرس‌وجویی را که ستاره دارد رد می‌کند — با حذف رشته‌ها و
کامنت‌ها، تا `'*'` در یک متن سئو باعث رد الکی نشود. دلیل: `select *` با هر
تغییر اسکیما، شکل پاسخ API را بی‌آنکه کسی تصمیم بگیرد عوض می‌کند.

## پیامدها

- هر ماژول دامنه (گام ۱۹ به بعد) از همین لایه رد می‌شود؛ هیچ SQL مستقیمی از API
  بیرون نمی‌زند.
- گارد مستأجر، فیلتر صریح را **اجباری** می‌کند و RLS حصار دوم می‌ماند.
- `pg` وابستگی همتا و اختیاری است: تست‌ها با موتور تعبیه‌شده می‌روند، تولید با
  درایور واقعی، و پکیج بدون هیچ‌یک هم بارگذاری می‌شود.
