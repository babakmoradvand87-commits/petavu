# ویترین B2B

هدف build مستقل: `npm run build:shop`. کد رابط فعلاً از کتابخانهٔ مشترک `src` ساخته می‌شود؛ خروجی این فضا جداست و مستقل قابل انتشار است.

برای Docker: `--build-arg APP_SCOPE=shop` و در زمان اجرا `APP_SCOPE=shop`.

جلسهٔ عملیاتی باید host-only و مخصوص این محیط باشد؛ احراز هویت و BFF هنوز پیاده‌سازی نشده‌اند. دسترسی به مسیر این صفحه در پیش‌نمایش، مجوز واقعی ایجاد نمی‌کند.
