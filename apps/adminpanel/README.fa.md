# مدیریت سایت و اعضا

هدف build مستقل: `npm run build:adminpanel`. کد رابط فعلاً از کتابخانهٔ مشترک `src` ساخته می‌شود؛ خروجی این فضا جداست و مستقل قابل انتشار است.

برای Docker: `--build-arg APP_SCOPE=adminpanel` و در زمان اجرا `APP_SCOPE=adminpanel`.

جلسهٔ عملیاتی باید host-only و مخصوص این محیط باشد؛ احراز هویت و BFF هنوز پیاده‌سازی نشده‌اند. دسترسی به مسیر این صفحه در پیش‌نمایش، مجوز واقعی ایجاد نمی‌کند.
